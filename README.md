# Lucsylo

Aplicativo gratuito de personalização para Windows 10 e 11 de 64 bits.

[Baixar Lucsylo para Windows](https://github.com/lucvolei12/lucsylo/releases/download/v0.1.0/Lucsylo-Windows.zip)

Baixe o ZIP, descompacte e abra Lucsylo.exe. Esta primeira versão ainda não foi testada em um computador Windows e o executável não possui assinatura digital. O Windows pode mostrar um aviso de segurança.
